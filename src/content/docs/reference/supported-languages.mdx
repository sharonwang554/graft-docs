Graft uses [tree-sitter](https://tree-sitter.github.io/) for deterministic, symbol-level AST parsing. The following languages are supported:

| Language | File Extensions |
|---|---|
| JavaScript | `.js`, `.jsx` |
| TypeScript | `.ts`, `.tsx` |
| Python | `.py` |
| Rust | `.rs` |
| Go | `.go` |
| Java | `.java` |
| C | `.c`, `.h` |
| C++ | `.cpp`, `.hpp`, `.cc`, `.cxx` |
| C# | `.cs` |
| Ruby | `.rb` |
| PHP | `.php` |
| Swift | `.swift` |
| Kotlin | `.kt`, `.kts` |
| Scala | `.scala` |
| Lua | `.lua` |
| Elixir | `.ex`, `.exs` |
| Haskell | `.hs` |
| OCaml | `.ml`, `.mli` |
| Zig | `.zig` |
| Bash | `.sh`, `.bash` |

Graft extracts functions, classes, interfaces, call edges, and dependency relationships from all supported languages.

## Filtering by language

Use `--extensions` to restrict builds to specific languages:

```bash
graft build --extensions .ts .py
```
