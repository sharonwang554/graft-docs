Trail-code wires Cursor, Codex and other `AGENTS.md` readers, Gemini CLI, GitHub Copilot, Windsurf, Kiro, Antigravity, Grok, Hermes and AdaL, and serves any agent that speaks MCP. One command does it:

```bash
npm install -g @trailhq/trail-code && trail init
# detects your agents and writes each one's native instruction file;
# Claude Code additionally gets the live statusline + hooks
```

## Pick agents interactively

On a terminal, `init` shows you every agent it knows about, flags the ones it detected (via their config directories), lists the exact files each would write, and wires only the ones you select. Claude Code is pre-selected; nothing else is.

Re-running only updates Trail-code's own section (or replaces the owned file) and never touches the rest of your content.

## Wire specific agents without a prompt

```bash
trail init --agents cursor kiro
```

To list the known agent ids:

```bash
trail init --list-agents
```

Other options:

- `trail init --yes` wires every **detected** agent.
- `trail init --all-agents` wires every known agent, detected or not.
- `trail init --dry-run` prints the agent wiring `init` would write, then exits without writing.

## Run init in CI or a script

With no TTY to prompt on (CI, a Dockerfile, a piped shell), `init` writes **nothing** and prints the command to run instead. Pass `--agents <ids>` or `--yes` to make a scripted run explicit.

## Keep writes inside the repo

Some agents also get user-level files, so the wiring follows you into worktrees and folders the repo's files don't reach. These apply to **every** repo you open with that agent. The picker labels them `machine-wide`, and `--dry-run` lists them in their own section. To skip them all while still wiring the repo's own files:

```bash
trail init --no-global
```
