Graft can generate visual representations of your codebase knowledge graph.

## Generate a visualization

```bash
graft viz
```

This produces a visual graph showing the nodes, relationships, and structure that Graft has built from your codebase.

## Use cases

- **Onboarding**: Help new team members understand codebase architecture at a glance.
- **Architecture reviews**: Visualize dependencies and relationships between subsystems.
- **Documentation**: Export graph visuals for architecture docs and design documents.
