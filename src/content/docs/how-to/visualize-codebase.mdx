`trail viz` opens a local, interactive view of both graphs. No install, no dev server; the viewer ships prebuilt inside the package.

![The graph viewer: searching a symbol and jumping to it lights up its dependency graph: amber edges are what it depends on, indigo is what depends on it](/assets/graft-viz-demo.gif)
*search → jump to a node → dependency graph lights up*

## Open the viewer

```bash
trail viz
```

The viewer has three tabs:

- **Context**: the architecture graph from `graft/*.md`. Nodes colored by type, sized by connectedness.
- **Code**: the per-symbol graph from `graft/.graph/wiring.json` (run `trail build` first).
- **Outline**: the file → class → method hierarchy as a collapsible tree.

## Read the edges

Select a node and its edges take on direction: **amber = what it depends on, indigo = what depends on it**, with the verb written on each highlighted edge. Chips above the canvas filter by verb. Edges the parser resolved exactly draw solid, while edges matched by name alone, or inferred by the model, draw dashed.

Every edge is one of a closed set of verbs. See [Edge verbs](/reference/graph-structure/#edge-verbs).

The viewer live-reloads when `graft/` changes on disk. Older graphs with vague verbs (`influences`, `supports`) are normalized on load, so no regeneration is needed.

## Export a single page

Write one self-contained `index.html` for CI, GitHub Pages, or a build artifact:

```bash
trail viz --export site/ --title "PR #12"
```
